计算机网络体系结构

计算机网络概述

计算机网络组成

从组成部分看
硬件

  • 主机／端系统（end system）：电脑、手机、物联网设备等

  • 通信设备：集线器、交换机、路由器等

  • 通信链路：网线、光纤、同轴电缆等

  • 网络适配器（网卡）：安装在端系统内部

    • 将主机数据发送到网络

    • 接收来自网络的数据

软件

  • 方便用户使用，实现资源共享

  • 如：Email 客户端、聊天软件、网盘软件

协议

  • 规定计算机网络中的通信规则

  • 由硬件 + 软件共同实现

    • 如：网络适配器 + 软件共同实现网络通信协议
从工作方式看（了解）
边缘部分

  • 直接为用户服务：通信、资源共享

  • 主要由接入互联网的主机及其软件组成

核心部分

  • 为边缘部分提供服务：连通性、交换服务

  • 由大量网络和连接这些网络的路由器组成

从逻辑功能看（了解）
资源子网

  • 运行应用程序，向用户提供可共享的硬件、软件和信息资源

  • 主要由接入互联网的主机组成

通信子网

  • 负责计算机之间的信息传输

  • 由 通信链路 + 通信设备 + 协议 构成

  • 主机内部用于信息传输的网络适配器、底层协议也属于通信子网

计算机网络的功能（了解）

数据通信

  • 实现计算机之间的数据传输

  • 是最基本、最重要的功能

资源共享

  • 共享硬件、软件、数据资源

  • 如：服务器处理、应用商店、视频分享

分布式处理

  • 将复杂任务分配给多台计算机处理

  • 如：大矩阵运算、MapReduce

提高可靠性

  • 多台计算机可互为替代

  • 如：服务器集群、数据冗余备份

负载均衡

  • 多台计算机共同分担繁重工作

  • 如：多台服务器均衡处理请求

电路交换、报文交换、分组交换

电路交换

建立连接（尝试占用通信资源）→ 通信（一直占用通信资源）→

释放连接（归还通信资源）

优点

  • 通信时延小：通信线路为双方专用，数据直达，传输效率高。

  • 有序传输：数据按发送顺序传送，不存在失序问题。

  • 没有冲突：不同通信对使用独立信道，不会争用物理信道。

  • 实时性强：物理通路一旦建立，双方即可随时通信。

缺点

  • 建立连接时间长：平均建立连接的时间对计算机通信而言过长。

  • 线路利用率低：物理通路被通信双方独占，即使空闲也无法供其他用户使用。

  • 灵活性差：通路中任一节点或链路发生故障，都需重新建立新连接。

  • 难以实现差错控制：中间节点不具备存储和检错能力，无法发现或纠正传输错误。

报文交换（message）

存储转发：先存储进中间结点，再根据目的地址转发至下一节点

优点

  • 通信前无需建立连接

  • 数据以“报文”为单位被交换节点间“存储转发”，通信线路可以灵活分配

  • 在通信时间内，两个用户无需独占一整条物理线路，相比于电路交换，线路利用率高

  • 交换节点支持“差错控制”（通过校验技术）

缺点

  • 报文不定长，不方便存储转发管理

  • 长报文的存储转发时间开销大、缓存开销大

  • 长报文容易出错，重传代价高

分组交换（packet）

  • 报文 Message：不定长

  • 分组 Packet：定长

    • 【首部】

      • 源地址、目的地址、分组号

    • 【数据】

  • 分组交换机：路由器

优点

  • 通信前无需建立连接

  • 数据以“分组”为单位被交换节点间“存储转发”，通信线路可以灵活分配

  • 在通信时间内，两个用户无需独占一整条物理线路，相比于电路交换，线路利用率高

  • 交换节点支持“差错控制”（通过校验技术）

相比报文交换，分组交换的改进

  • 分组定长：方便存储转发管理

  • 存储转发开销小、缓存开销小

  • 分组不易出错，重传代价低

缺点

  • 相比报文交换，控制信息占比增加

  • 相比电路交换，仍存在存储转发时延

  • 报文被拆成多个分组，可能出现失序、丢失等问题，处理更复杂

虚电路交换 —基于分组交换

  • 建立连接（虚拟电路）

  • 通信（分组按序、按照已建立好的既定线路发送，不独占线路）

  • 释放连接

计算机网络的分类

分布范围

  • 广域网 WAN

  • 城域网 MAN

    • 以太网技术

  • 局域网 LAN （以太网）

    • 以太网技术

    • （以太网）交换机，用以连接局域网内部的各个节点

  • 个域网 PAN

    • 无线技术连接个人设备（无线个域网 WPAN）

    • 蓝牙

传输技术

  • 广播式网络

    • 广播范围内所有计算机都会收到分组，并根据目的地址判断是否接收

    • 所有无线网络都是广播式

  • 点对点网络

    • 1 to 1 精准送达

    • 路由器转发的数据分组

拓补结构

  • 总线形 局域网

    • 数据 “广播式” 传输，存在 “总线争用” 的问题

    • e.g. 集线器 （物理上：星形拓补，逻辑上：总线形）

  • 环形 局域网

    • 数据 “广播式” 传输，通过令牌（Token）解决

      “总线争用” 的问题

    • e.g. 令牌环网

      （同一时间段只有一人持有令牌，只有持有令牌才能发送数据，A结束后将令牌传给B…）

  • 星形 局域网

    • 由 中央设备 实现数据 点对点

      传输，不存在总线争用 问题（检查目的地址）

    • e.g. 以太网交换机

  • 网状 广域网

    • 数据通过各个中间节点注意存储转发，点对点，分组交换

    • e.g. 众多路由器构成的广域网

使用者

  • 公用网：向公众开放的

  • 专用网：组织内部使用的内网

传输介质

  • 有线网络

  • 无线网络

速率 Speed

网络中传输数据的速率，也称数据率、比特率、数据传输速率。

  • 常用单位：bit/s、b/s、bps。

  • 有时也用 B/s：

⚠️ 带宽 Bandwidth

  • 信道所能传送的最高数据率

  • 表示信道允许通过的信号频率范围（Hz）

节点间通信实际能达到的最高速率，由带宽、节点性能共同控制，信道带宽越大，传输数据的能力越强

吞吐量 Throughput

单位时间内，通过某个网络（或信道、接口）的实际数据量，受带宽限制、复杂的网络负载情况影响（某个设备/网络算来去的总的）

  • 信道 1 的吞吐量：1.8MB/s

  • 信道 2 的吞吐量：93.3MB/s

  • 网线的吞吐量：95.1MB/s

  • 电脑网卡的吞吐量：95.1MB/s

计算机网络分层结构

功能

  • 差错控制

  • 流量控制

  • 分段和重装

  • 复用和分用

  • 建立连接和释放

各层之间的关系

  • 实体（Entity）

    • 第 𝑛 层中的活动元素（软件 + 硬件）称为第 𝑛 层实体

    • 不同机器上的同一层称为对等层

    • 同一层的实体称为对等实体

  • 协议（Protocol）

    • 控制对等实体之间通信的规则集合

    • 是水平的

  • 接口（Interface）

    • 同一节点内相邻两层实体交换信息的逻辑接口

    • 又称服务访问点（SAP）

  • 服务（Service）

    • 下层为上层提供的功能调用

    • 是垂直的

PDU, SDU, PCI

  • 协议数据单元（PDU）：对等层次之间传送的数据单位（这一层整个）

  • 服务数据单元（SDU）：为完成上一层实体所要求的功能而传送的数据（上一层的完整信息）

  • 协议控制信息（PCI）：控制协议操作的信息（这一层新加的控制信息）

协议的三要素

协议控制对等实体之间通信的规则集合，是水平的

  • 语法：数据与控制信息的格式

    • 协议的控制信息（首部）部分占几个字节、每个字节的含义

  • 语义：需要发出何种控制信息、完成何种动作、做出何种应答

    • 发送完后，接收方是否需要应答，应答什么（成功 / 失败）

  • 同步 /

    时序：执行各种操作的条件、时序关系等，即时间实现顺序的详细说明

    • 发送完后，接收方需立即应答，如 10 s

      内未收到应答，则发送方会再次发送数据

物理层

物理层

实现相邻节点间比特（0/1）传输

  • 定义电路接口参数：形状、尺寸、引脚数等

  • 定义传输信号特性：0/1 对应电压、每比特持续时间等

链路层

确保相邻节点间链路逻辑上无差错

  • 差错控制（局部）：检错 + 纠错，或检错 + 丢弃 + 重传

  • 流量控制：协调两节点的传输速率

  • 传输单位：帧（Frame）

网络层

将分组从源节点转发到目的节点

  • 路由选择：选择最佳路径

  • 分组转发：从合适端口转发分组

  • 拥塞控制：检测并缓解网络拥塞

  • 网际互联：实现异构网络互联

  • 其他：差错控制（全局）、流量控制、连接建立与释放（虚电路、有序）、可靠传输管理（ACK）

  • 网络层提供

    • 数据报：无连接不可靠

    • 虚电路：有连接可靠

  • 传输单位：分组（Packet）

传输层

实现端到端通信，即进程到进程通信

  • 复用与分用

    • 发送端：多个高层实体复用下层连接

    • 接收端：再将数据分用给对应进程

  • 其他：差错控制、流量控制、连接建立与释放、可靠传输管理（ACK）

  • 传输单位：报文段（Segment）

#5 ~ #7 层

  • 【应用层】

    • 实现特定网络应用

  • 【表示层】

    • 数据格式转换：统一编码、压缩、加密

  • 【会话层】

    • 会话管理、断点续传
