功能一览

这个示例站覆盖以下写作和阅读场景，可直接打开相应页面体验。

场景可体验内容
文章与栏目日期、文章列表与 RSS
数学写作可复制公式、编号与引用、文献
丰富内容图片、合并表格、旁注、代码与脚注
长文阅读多层标题、目录、宽表与学习题
下载与保真可打印 PDF、CSV 附件

试一试

  1. 切换右上角的明暗主题。
  2. 缩窄浏览器，检查长公式和宽表的局部滚动。
  3. 打开长文目录，跳转到不同章节，再回到顶部。
  4. 在公式或代码块上使用复制功能。
  5. 从下载页打开独立 PDF。

站内保留一篇未公开的草稿，用于验证发布清单。它不会出现在文章索引、订阅或公开仓库中。
